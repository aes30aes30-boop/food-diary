# Дневник питания — инструкция по публикации

Код готов. Осталось два шага: подключить базу данных (Supabase) и опубликовать сайт (Vercel).
Всё делается через сайты в браузере, без программирования.

## Шаг 1. Supabase (хранит логины и записи)

1. Зайдите на https://supabase.com и зарегистрируйтесь (можно через Google).
2. Нажмите "New project". Придумайте имя и пароль от базы данных (сохраните его куда-нибудь), выберите регион (ближайший к вам).
3. Подождите 1–2 минуты, пока проект создастся.
4. Слева в меню откройте "SQL Editor" → "New query".
5. Откройте файл `supabase-schema.sql` из этой папки, скопируйте весь текст и вставьте в редактор. Нажмите "Run".
   Это создаст таблицы для записей, воды и настроек.
6. Слева откройте "Project Settings" (шестерёнка) → "API".
7. Найдите там:
   - "Project URL" — скопируйте.
   - "anon public" ключ — скопируйте.

## Шаг 2. Вставьте ключи в проект

1. В папке проекта найдите файл `.env.example`, сделайте его копию и переименуйте в `.env`.
2. Откройте `.env` любым текстовым редактором и вставьте туда значения из Supabase:
   ```
   VITE_SUPABASE_URL=вставьте сюда Project URL
   VITE_SUPABASE_ANON_KEY=вставьте сюда anon public ключ
   ```

## Шаг 3. Публикация на Vercel

1. Зайдите на https://vercel.com и зарегистрируйтесь (удобнее всего — через GitHub).
2. Если аккаунта на GitHub нет — зарегистрируйтесь на https://github.com, это тоже бесплатно.
3. Загрузите папку проекта на GitHub (самый простой способ — на github.com нажать "New repository", затем перетащить файлы через кнопку "uploading an existing file"). Файл `.env` загружать НЕ нужно — он и так исключён (см. `.gitignore`).
4. В Vercel нажмите "Add New" → "Project", выберите загруженный репозиторий.
5. В настройках проекта перед публикацией откройте "Environment Variables" и добавьте те же две переменные, что и в `.env`:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
6. Нажмите "Deploy". Через минуту получите ссылку вида `https://ваш-проект.vercel.app` — это и есть ваш сайт.

## Что дальше

- По умолчанию Supabase присылает письмо для подтверждения email при регистрации. Это можно отключить в Supabase: Authentication → Providers → Email → выключить "Confirm email" — тогда друзья смогут пользоваться сразу после регистрации.
- Если что-то не получается на каком-то шаге — пришлите скриншот, разберёмся вместе.
